# سورس اختصاصی HEIC Pro Converter V6 Silver Studio

این پروژه نسخه بازطراحی‌شده اختصاصی مبدل تصاویر برای Windows 10 64-bit است.

## قابلیت‌ها
- تبدیل HEIC و HEIF به JPG
- پذیرش مستقیم JPG و JPEG
- عدم فشرده‌سازی مجدد JPGهایی که از قبل زیر حجم هدف هستند
- حجم هدف پیش‌فرض 488KB
- جست‌وجوی کیفیت و کاهش ابعاد فقط در صورت نیاز
- پردازش موازی تا 6 فایل
- Preview واقعی تصویر
- رابط Silver Studio با چیدمان نرم‌افزارهای تجاری دسکتاپ
- منوی بالای ویندوز، Toolbar، مشخصات فایل، جابه‌جایی ترتیب فایل‌ها و پوشه خروجی
- استفاده از Far.Nazanin و Far.Titr در صورت نصب بودن روی ویندوز؛ در غیر این صورت Tahoma جایگزین می‌شود
- بدون Qt و بدون وابستگی PySide6

## هدف سیستم
- Windows 10 64-bit
- Python 3.8 x64 برای Build رسمی این پروژه
- خروجی نهایی PyInstaller به‌صورت EXE تک‌فایلی

## ساختار پروژه
```text
heic-pro-converter/
├─ src/
│  ├─ app.py          رابط کاربری V6 Silver Studio
│  └─ converter.py    موتور تبدیل، فشرده‌سازی و پردازش JPG/HEIC
├─ requirements.txt
├─ run_dev.bat        اجرای مستقیم سورس روی ویندوز
├─ build_win10_x64.bat ساخت EXE مخصوص Windows 10 x64
└─ README_SOURCE_FA.md
```

## اجرای سورس
1. Python 3.8 نسخه 64-bit را نصب کنید.
2. فایل `run_dev.bat` را اجرا کنید.
3. در اجرای اول محیط مجازی و کتابخانه‌ها نصب می‌شوند.

## ساخت EXE
فایل زیر را اجرا کنید:
```text
build_win10_x64.bat
```
خروجی نهایی در مسیر زیر ساخته می‌شود:
```text
dist\HEIC-Pro-Converter-v6-Silver-Studio.exe
```

## وابستگی‌ها
- Pillow 10.4.0
- pillow-heif 0.18.0
- customtkinter 5.2.2
- PyInstaller 6.11.1

## نکته فونت
فایل فونت داخل سورس یا EXE توزیع نشده است. برنامه در صورت نصب بودن فونت‌های Far.Nazanin و Far.Titr روی ویندوز از آن‌ها استفاده می‌کند و در غیر این صورت بدون خطا با Tahoma اجرا می‌شود.

## نکته 488KB
منظور پروژه از 488KB برابر `488 × 1024` بایت است. موتور تلاش می‌کند بیشترین کیفیت JPEG ممکن را در این سقف نگه دارد و فقط وقتی لازم باشد ابعاد تصویر را کاهش می‌دهد.

## فایل‌های اصلی برای توسعه

- تغییر الگوریتم تبدیل و حجم: `src/converter.py`
