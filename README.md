# چیدمان‌یار دیویی

برنامه‌ای آفلاین و فارسی برای ثبت اجزای برچسب عطف کتاب و تعیین ترتیب صحیح چیدمان کتاب‌ها در قفسه بر پایه رده‌بندی دهدهی دیویی.

## امکانات

- ثبت جداگانه شماره اصلی و اعشار رده
- ثبت نشانه مؤلف، عدد مؤلف و نشانه اثر
- پشتیبانی از جلد، نسخه و سال انتشار
- پذیرش اعداد فارسی، عربی و انگلیسی
- تشخیص خودکار یکی از ده رده اصلی دیویی
- پیش‌نمایش برچسب عطف
- جدول ثبت اولیه و جدول چیدمان صحیح
- نمایش جایگاه اولیه، جایگاه صحیح و علت تقدم
- تشخیص برچسب‌های تکراری
- ویرایش، حذف، جست‌وجو و پشتیبان‌گیری
- ذخیره دائمی روی گوشی و کارکرد بدون اینترنت

## ترتیب مقایسه

1. شماره اصلی رده
2. اعشار رده
3. حرف نشانه مؤلف
4. عدد نشانه مؤلف به صورت اعشاری
5. نشانه اثر
6. شماره جلد
7. شماره نسخه
8. سال انتشار
