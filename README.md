# چیدمان‌یار دیویی

اپلیکیشن Native و کاملاً آفلاین Android برای ثبت اجزای برچسب عطف، نگهداری جدول ثبت اولیه و محاسبه خودکار ترتیب صحیح کتاب‌ها در قفسه بر پایه رده‌بندی دهدهی دیویی.

## قابلیت‌ها

- رابط کاملاً فارسی و RTL با Material 3 و فونت Vazirmatn
- ثبت، ویرایش، حذف و بازیابی حذف با Undo
- ثبت جداگانه شماره اصلی، اعشار رده، حرف و عدد مؤلف و نشانه اثر
- ساخت خودکار شناسه عددی تصادفی و قابل ویرایش برای هر کتاب جدید
- حرکت خودکار به فیلد بعدی پس از تکمیل مقدار یا پایان کوتاه تایپ
- ورود صوتی فارسی برای همه فیلدهای فرم، بدون درخواست مجوز دائمی میکروفن
- پشتیبانی از جلد، نسخه و سال انتشار
- پذیرش ارقام فارسی، عربی و لاتین
- پیش‌نمایش زنده برچسب عطف
- جدول ثبت اولیه همراه با جست‌وجوی سریع
- جدول چیدمان صحیح همراه با جایگاه اولیه، جایگاه صحیح و میزان جابه‌جایی
- نمایش دلیل تقدم هر کتاب در چیدمان
- تشخیص برچسب‌های تکراری
- راهنمای ده رده اصلی و اولویت مقایسه
- خروجی و بازیابی پشتیبان JSON با Storage Access Framework و بدون مجوز حافظه
- ذخیره‌سازی پایدار در Room و کارکرد بدون اینترنت
- محاسبه و Cache ترتیب قفسه خارج از رشته اصلی رابط برای اجرای روان‌تر
- حالت‌های Loading، Empty، No Result و Error
- پشتیبانی از گوشی و چیدمان تطبیقی برای نمایشگرهای عریض

## قواعد مرتب‌سازی

مقایسه از بالا به پایین انجام می‌شود:

1. شماره اصلی رده
2. اعشار رده به‌صورت رقم‌به‌رقم
3. حرف نشانه مؤلف بر پایه ترتیب الفبای فارسی
4. عدد مؤلف به‌صورت اعشاری؛ برای نمونه `ب۵۱ < ب۵۱۶ < ب۵۲`
5. نشانه اثر
6. شماره جلد
7. شماره نسخه
8. سال انتشار
9. عنوان و زمان ثبت فقط برای شکستن برابری کامل

## معماری

```text
app/src/main/java/ir/deweyshelf/app/
├── core/           Design System، Theme و ابزارهای فارسی
├── data/           Room، Repository و پشتیبان JSON
├── domain/         مدل‌ها، اعتبارسنجی و موتور مرتب‌سازی
└── presentation/   ViewModel، Navigation، Components و Screens
```

UI مستقیماً به Room متصل نیست. جریان داده از `BookRepository` و `DeweyViewModel` عبور می‌کند و موتور مرتب‌سازی یک بخش مستقل و قابل تست است.

## فناوری‌ها

- Kotlin 2.0.21
- Jetpack Compose + Material 3
- Navigation Compose
- Room 2.8.4 + KSP
- Kotlin Coroutines و Flow
- Android Gradle Plugin 8.7.3
- حداقل Android 6.0 / API 23

## Build

با JDK 17، Android SDK 35 و Gradle 8.10.2:

```bash
gradle testDebugUnitTest lintDebug assembleDebug
```

خروجی محلی در مسیر زیر ساخته می‌شود:

```text
app/build/outputs/apk/debug/app-debug.apk
```

GitHub Actions پس از هر تغییر در شاخه `main` تست‌ها، Lint و Build را اجرا می‌کند و APK به‌همراه SHA-256 را در پوشه `apk` قرار می‌دهد.

## تست‌ها

- Unit Test ترتیب اعشار دیویی
- Unit Test ترتیب عدد مؤلف
- Unit Test تشخیص برچسب تکراری و جایگاه صحیح
- Unit Test اعتبارسنجی و ارقام فارسی
- Unit Test تولید شناسه عددی تصادفی کتاب
- Instrumented Test عملیات درج، ویرایش و حذف Room

## امنیت و حریم خصوصی

- برنامه مجوز اینترنت، دوربین، مکان، مخاطبان یا حافظه درخواست نمی‌کند.
- داده‌ها فقط در پایگاه‌داده داخلی برنامه ذخیره می‌شوند.
- انتخاب محل پشتیبان‌گیری از طریق انتخابگر امن فایل Android انجام می‌شود.
- هیچ کلید API یا داده حساس در سورس وجود ندارد.

## امضای انتشار

APK خودکار فعلی با کلید Debug ساخته می‌شود و برای نصب و تست مستقیم مناسب است. برای انتشار در Google Play باید Keystore اختصاصی مالک برنامه به‌صورت GitHub Secret تنظیم و نسخه Release/AAB امضا شود؛ هیچ کلید خصوصی در مخزن نگهداری نمی‌شود.

فونت Vazirmatn تحت مجوز SIL Open Font License در برنامه بسته‌بندی شده و متن مجوز در `app/src/main/assets/licenses` موجود است.
